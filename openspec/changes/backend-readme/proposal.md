## Why

The `apps/backend/` directory currently lacks comprehensive documentation. Developers joining the project or working on integrations need clear documentation covering the API structure, authentication flows, WebSocket events, database schema, and setup instructions. A well-structured README will reduce onboarding friction and serve as a quick reference for the backend's capabilities.

## What Changes

- **New `apps/backend/README.md`**: Comprehensive documentation covering project overview, API reference, authentication, WebSocket events, database schema, environment configuration, and development workflow
- **API Documentation Links**: Reference to OpenAPI/Scalar docs at `/docs` endpoint
- **Architecture Overview**: Visual representation of the backend module structure and request flows
- **Quick Start Guide**: Step-by-step setup for local development
